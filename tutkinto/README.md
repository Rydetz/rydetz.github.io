# Tieto- ja viestintätekniikan perustutkinto

Viisisivuinen responsiivinen verkkosivu, joka on tehty HTML:llä ja CSS:llä.

Sisältö on muokattu HTML-muotoon [datamonnit/ohj-www-responsiiviset-sivut](https://github.com/datamonnit/ohj-www-responsiiviset-sivut) -repositorion Markdown-tiedostoista.

Avaa `index.html` selaimessa. Kaikki sivut ja `styles.css` kuuluvat samaan kansioon.

Sivut: Etusivu, Tutkinnon rakenne, Tutkinnonosat, Kriteerit ja Arviointi.
